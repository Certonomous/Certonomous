# Demo surfaces

One-stop folder for the live demo: browse here when clicking "Load a surface (STL / OBJ)" in the GUI.

- `motorBike.obj` — Act 2 motorcycle CFD
- `b52.stl` — Act 2 B-52 CFD
- `naca4412_wing.stl` — Act 2b validated wing + race act
- `naca0012_wing.stl` — spare validated body

Note: these are copies of the staged surfaces in `sdk/geometry`. The originals there are load-bearing for the backend's named-body resolver — do not move or edit them.
