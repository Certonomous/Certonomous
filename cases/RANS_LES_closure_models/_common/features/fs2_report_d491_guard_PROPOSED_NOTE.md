statistic **by value at six render precisions**, not by key name, and refuses
(exit 2) unless `D491_RELEASE` names the docket id of a registered instrument
decision adopting verification's recommendation (a). Three properties matter:

* It is a **value** scan, so it would have caught the seven existing
  occurrences that the name sweep declared absent.
* It carries a **planted control** (rule 3): it renders a known forbidden value

* Its refusal message **withholds the value**. A refusal that prints the figure
  it is refusing to print defeats itself.

**Proved, without running the generator.** The scan logic was exercised in
isolation against the HEAD blob of `FS2_DEGENERACY_REPORT.md` with the six
pre-D476 values supplied as literals (no file under `/home/ubuntu/closure-data/`

  the table in §2 above exactly;
* name scan over the same text → **0**, reproducing the board's false clean;
* planted control → 1 hit on the plant, 0 on clean text (both directions live).
