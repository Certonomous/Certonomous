## The defect (real, L-504 clause-(c) class — the 4th this session)

The frozen rig `so3dr_stage2_standalone_runScript.py` writes `injected_dv.json`
AFTER `prob.run_model()`. The 32/36 legs whose primal legitimately fails
(`Primal solution failed!` — the very outcome being counted) therefore never write
the sidecar. The frozen grader `so3dr_stage2_grade.py` (blob `8f7ca638`, md5
`2d32ec9b`, INTACT) refuses at `falsifier_f4_echo()`:240-241 on the first
sidecar-absent leg — before F2/F3 grading — so the whole run hard-refuses.

This is the unguarded-expected-raised-state class: F4's absence-refuse was meant to
catch a tampered/skipped leg, but the rig's write-ordering makes a **legitimately
failed primal** trip the same refuse. The defect is genuine.

## Why §2d.1 does not reach it — two independent grounds, either sufficient

1. **No recorded value exists to be invariant to.** The frozen grader produced a
   REFUSE (exit 2), declaring no six-token verdict. §2d.1 repairs a grading path
   that produced a *wrong value* and reproduces the *correct value byte-identically*
   (its value-invariance test). It is not a vehicle to manufacture a first verdict
   where the frozen instrument refused; there is nothing for the repair to be
   byte-identical to.

2. **The proposed fix changes what F4 verifies, and lives outside the frozen path.**
   For the 32 failed legs the fix drops F4's stronger arm — the injected
   design-vector `shape_md5`/`twist_md5` check (`:244-245`) whose input was never
   written — and keeps only the weaker AoA log-echo arm (`:249-251`). Weakening the
   falsifier for 89% of the failed subpopulation is not value/logic-invariant. And
   the fix is an untracked monkeypatch (`so3dr_stage2_diag_regrade.py`, header
   "DIAGNOSTIC ONLY — NOT THE OFFICIAL VERDICT"); the frozen grader blob is
   unchanged. §2d.1 requires the frozen grading path be repaired *in place* with a
   dated re-pin addendum — a parallel monkeypatched instrument is not that.

Consistent with the V-125 discriminator: §2d.1 iff no gate/threshold/cap/label/value
moves and the frozen path is repaired in place; a change to *what is computed or
verified* needs a fresh frozen successor (D9 §10). Contrast the two §2d.1 grants:
D9-DEF-2 (same-inode symlink, logic untouched, verdict unchanged) and F27 R2
(default-arg on the run root, same frozen logic on the same data, re-run
byte-identical). SO3DR-F4 is neither.

## The lawful vehicle — a fresh successor (root-cause fix)

Reorder the frozen rig to write `injected_dv.json` BEFORE `prob.run_model()` so the
sidecar exists for every leg including a failed primal, giving F4's md5 arm its
input. Re-freeze the rig + grader, re-register (D9's own §10: a change to what is
produced needs a fresh pre-registration), and re-run (~55 core-min, fail-fast). The
gate/threshold/bands are NEVER widened — the successor fixes OUR instrument so F4 can
run at full strength; it does not adjust the bar (T25 anti-gaming stands).
