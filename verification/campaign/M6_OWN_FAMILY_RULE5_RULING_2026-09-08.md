## Ruling — on existing law (rule 5 + Coverage-Matrix G); NO standard relaxed

1. **Rule 5 requires a CONVERGING TRIPLE, an OBSERVED order, and GCI at Fs = 1.25.** Its gating order
   is written over THREE values — order (3) "CONVERGING" is a property of a triple, and "never quote a
   GCI when the three values are not monotone" presupposes three values. The Coverage-Matrix **G**
   column certifies exactly this: *"a CONVERGING Roache triple, GCI at Fs = 1.25, AND an observed
   order."*

2. **A two-level pair with an ASSUMED p is structurally NOT a rule-5 CONVERGING triple.** With two
   levels the order is assumed, not measured, and there is no three-value monotonicity to classify.
   Rule 5 cannot grade such a pair PASS; as a *gated* row its triple status is not CONVERGING, so under
   rule 5's own order it is **NOT A RESULT** — it cannot carry a credential-grade order or a HOLDS **G**.

3. **For a credential-grade M6-Cp grid-convergence order, PATH B is the answer** — the fine triple
   {L2,L1,L0}. Coarsening being proven infeasible, the triple is built by refining UP to L0; this is
   feasible and cheap ($0.91, inside the envelope), so **there is no capability-gap defense for path A
   as a credential** — a triple IS achievable. (A capability-gap filing under §2ay state (a) would
   require unrecoverability MEASURED; refining up is neither impossible nor blocked, so that door is
   shut.)

4. **Path A is admissible ONLY as a non-credential, honestly-labelled artifact** — a two-level
   Richardson pair, assumed p = 2, reported as a lower-bound / no-observed-order band, EXPLICITLY NOT a
   rule-5 CONVERGING triple and NOT graded PASS (mirroring the M6SR **L-HONEST** labelling). Used and
   labelled this way it makes NO rule-5 gated claim, so it does NOT relax rule 5 and needs no
   escalation. It may serve as an interim survey band while L0 is built; it is NOT the credential and
   NOT a HOLDS / G row.

5. **The HARD GUARDRAIL is NOT tripped.** This ruling APPLIES rule 5 as written (it holds the line);
   it does not relax it. Accepting path A *as a rule-5 credential-grade order* WOULD relax rule 5 and
   is reserved to Sanaa — I do not do that. Because I hold the line rather than relax it, this is
   application of existing law and does **not** escalate to Sanaa.
